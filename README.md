# PHT Sales Engine

Curated webshop for lighting, audio, furniture, and home tech.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Client-side cart (localStorage)

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Full-bleed brand landing
- Product catalog and detail pages
- Cart drawer with quantity controls
- Demo checkout flow
